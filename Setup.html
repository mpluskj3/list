1단계: Supabase 데이터베이스 연결 설정
Supabase 대시보드(Project Settings → API)에서 발급받은 Project URL과 anon / public Key를 입력해 주세요. 입력 후 [연결 테스트 & 저장]을 실행하여 연동 상태를 실시간으로 검증할 수 있습니다.
기본 연결 정보 안내
글로벌 설정을 사용하시거나, 자체 구축한 커스텀 DB 연결 정보를 저장하여 전용 데이터베이스로 연동할 수 있습니다.
예: https://rrgjwzzjuftvnqcgipli.supabase.co
공개 가능한 API anon Key를 입력해 주세요.
2단계: 데이터베이스 스키마 및 테이블 검증
Supabase SQL Editor에서 supabase_schema.sql 스크립트를 실행하여 데이터베이스 테이블을 구축해야 합니다. 아래 버튼을 눌러 필수 9개 테이블이 모두 정상적으로 생성되었는지 자동 검증하세요.
supabase_schema.sql 스크립트
-- Supabase Schema for SheetViewer CREATE EXTENSION IF NOT EXISTS "uuid-ossp"; CREATE TABLE IF NOT EXISTS public.schedules ( ... ); CREATE TABLE IF NOT EXISTS public.publishers ( ... ); CREATE TABLE IF NOT EXISTS public.assignment_history ( ... ); CREATE TABLE IF NOT EXISTS public.public_talk_outlines ( ... ); CREATE TABLE IF NOT EXISTS public.public_talks ( ... ); CREATE TABLE IF NOT EXISTS public.admin_users ( ... ); CREATE TABLE IF NOT EXISTS public.navigation_links ( ... ); CREATE TABLE IF NOT EXISTS public.app_settings ( ... ); CREATE TABLE IF NOT EXISTS public.database_connections ( ... );
3단계: 초기 관리자 계정 & Seed 데이터 검증
시스템 관리를 위해 기본 관리자 계정(관리자 / 1234)과 초기 메뉴 항목이 등록되어 있어야 합니다. 데이터베이스에 초기 데이터가 없으면 [Seed 데이터 즉시 생성]을 눌러 바로 생성할 수 있습니다.
로그인 보안 권장 사항
기본 관리자 계정으로 첫 로그인 후, [관리자 패널 → 설정 → 관리자 계정 관리] 메뉴에서 비밀번호를 반드시 변경해 주세요.
관리자 로그인 테스트 (실시간 검증)
4단계: 회중 맞춤 설정 (Congregation Settings)
회중 이름, 회중 유형(한국어 vs 수어회중), 기본 글꼴 등을 설정합니다. 설정 내역은 DB의 app_settings 테이블에 즉시 저장됩니다.
수어 회중 선택 시: [통역] 뱃지, SL 체크박스, 통역자 명단, 농인 구분 필드가 자동 활성화됩니다.
